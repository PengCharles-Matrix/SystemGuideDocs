# Tailwind CSS v4

## Purpose

Tailwind CSS provides utility classes for layout, spacing, typography, colors, responsive behavior, and component styling.

## Required version

Tailwind CSS v4 is mandatory for the next project.

## Project rules

- Do not introduce an older Tailwind version.
- Keep styling primarily in Tailwind utilities and project design tokens.
- Build reusable components instead of repeating large class strings unnecessarily.
- Keep responsive behavior explicit and consistent.
- Avoid ad-hoc CSS when a Tailwind utility or project token is appropriate.

## Verification

Confirm the installed Tailwind package is v4 and verify the Vite integration before development begins.
