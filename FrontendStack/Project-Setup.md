# Frontend Project Setup

## Baseline

The next project should start with React 19, TypeScript, Tailwind CSS v4, and Vite.

## Initial workflow

1. Create the Vite React TypeScript project.
2. Install and configure Tailwind CSS v4 using the current official integration for Vite.
3. Verify React and React DOM are version 19.
4. Enable strict TypeScript checking.
5. Initialize Git.
6. Create the main branch and push it to the remote repository.
7. Create the first feature branch before application work.

## Example project commands

npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
npm run dev

Tailwind v4 setup should follow the current project template/integration rather than copying configuration from Tailwind v3 projects.

## First verification

npm run build
