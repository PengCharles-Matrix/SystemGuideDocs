# Vite

## Purpose

Vite provides the development server, fast module replacement, and production build pipeline for the frontend.

## Required role

Vite is the enforced frontend build tool. Do not replace it with another frontend bundler for the standard project.

## Common commands

npm run dev      start development server
npm run build    create production build
npm run preview  preview production build locally

## Port

Vite development commonly uses port 5173. Vite preview commonly uses port 4173. The project's configuration may override these defaults.

## Verification

Confirm the scripts in package.json and the Vite configuration before changing build behavior.
