# Frontend Stack Standard

This guide defines the mandatory frontend baseline for the next project.

## Enforced stack

- React 19 — UI component framework.
- TypeScript — typed application code.
- Tailwind CSS v4 — utility-first styling.
- Vite — development server and production build tool.

## Enforced Git workflow

- Work must be done on feature or fix branches.
- Direct development on main is not allowed.
- Changes must be submitted through Pull Requests.
- PR checks and review must pass before merging.

## Core principle

Keep application code typed, componentized, testable, and reviewable.

See the other documents in this folder for installation, architecture, and workflow details.
